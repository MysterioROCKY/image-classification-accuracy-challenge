# Image Classification Accuracy Challenge

This repository contains implementations of CNN-based image classification models developed as part of the *Image Classification Accuracy Challenge* assignment. The project aims to classify images from two popular datasets — **MNIST** and **STL-10** — using CNN architectures in **PyTorch**.
